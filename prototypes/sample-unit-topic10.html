How should a unit read as a plan the coach can run?

One compact run sheet for gi half guard. Draft is the Build proposal. Read is the plan the coach teaches from. Edit is the same sheet with packing and citation controls. Technique rows spell out step bullets. A glued drill shows only the partner job.

What this prototype is checking

Same surface, three modes. Class cards keep the unit organized. In Edit, the coach drags a class cut, adds or removes lessons, and chooses citations from the lesson's named move or system.
